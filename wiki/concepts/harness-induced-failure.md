# Harness-Induced Failure

Harness-induced failure is when a model has enough capability to solve a task, but the surrounding system prevents it from doing so reliably.

The lecture uses controlled experiments to make this concrete: the same model can fail in a bare prompt-only setup and succeed when the harness adds planning, generation, evaluation, verification, and state persistence.
