# Diagnostic Loop

The diagnostic loop is the repeatable process of executing a task, observing the failure, attributing it to a specific harness layer, fixing that layer, and running again.

The lecture recommends treating each failure as a signal. If the same model keeps failing in the same way, the next move is to repair the harness, not to blame the model in the abstract.
