# Agent State Management

Agent state management is the part of harness engineering that preserves useful work across sessions.

The lecture treats the repository as the system of record. Notes, architectural decisions, and partially completed work should live somewhere persistent so a fresh session does not have to rediscover the same facts from scratch.
