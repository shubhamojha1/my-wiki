# Full-Text Index

A **full-text index** is designed for efficient searching of text data, enabling natural language queries like word and phrase matching.

## Characteristics

- **Word-level indexing**: Breaks text into tokens (words)
- **Stop words**: Filters out common words (the, a, is)
- **Stemming**: Matches word variants (run, runs, running)
- **Ranking**: Results ordered by relevance
- **Best for**: Large text columns, search functionality

## Common Uses

- Search engines and document retrieval
- Blog/article content search
- Product description search in e-commerce
