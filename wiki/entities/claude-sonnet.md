# Claude Sonnet

Claude Sonnet is the model family name used in the lecture's engineering example about adding API endpoints to a Python web app.

The point of the example is not that the model was weak. It is that the model needed a stronger harness: project conventions, explicit verification commands, and saved architectural context.
