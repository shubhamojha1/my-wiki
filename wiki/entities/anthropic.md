# Anthropic

Anthropic is an AI company whose models are used in the lecture as evidence that harness quality can dominate agent performance.

The lecture cites a controlled experiment where the same model and prompt were run twice. The weak setup failed quickly. The stronger setup added planner, generator, and evaluator roles and produced a working result.
