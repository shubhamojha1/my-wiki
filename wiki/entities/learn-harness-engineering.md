# Learn Harness Engineering

`Learn Harness Engineering` is a lecture series about making coding agents reliable through better task framing, repository conventions, validation, and state management.

Lecture 01 argues that model capability is only one input to success — the harness around the model determines whether the agent can understand the task, execute it cleanly, and prove that it is finished. Lecture 02 follows up with a precise structural definition: a harness is exactly five subsystems (instruction, tool, environment, state, feedback), and a project can be audited against that model directly.
