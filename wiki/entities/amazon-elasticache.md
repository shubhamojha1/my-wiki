# Amazon ElastiCache

**Type:** Managed in-memory data store and cache service  
**Website:** [aws.amazon.com/elasticache](https://aws.amazon.com/elasticache/)

## Overview

Amazon ElastiCache makes it easy to deploy, operate, and scale an in-memory data store or cache in the cloud. It improves web application performance by allowing retrieval from fast, managed, in-memory data stores instead of slower disk-based databases.

## Supported Engines

- [[Redis|ElastiCache for Redis]] — full-featured in-memory data structure store with replication, persistence, and high availability
- [[Memcached|ElastiCache for Memcached]] — pure in-memory key-value cache, simple and fast

## Key Capabilities

- Sub-millisecond latency
- Hundreds of thousands of IOPS per instance
- Managed deployment, scaling, and operations
- Acts as distributed side-cache or standalone in-memory database
- Supports high availability via Redis replication
- Handles read-heavy workloads: Q&A portals, gaming, media sharing, social networking

## Use Cases

- Database query result caching
- Session management (centralized HTTP session store)
- API response caching
- Real-time leaderboards (gaming)
- IoT time-series data
- Real-time bidding (AdTech)
- Recommendation engine data layer
