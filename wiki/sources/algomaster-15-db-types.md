# AlgoMaster: 15 Types of Databases

**Author:** Ashish Pratap Singh
**URL:** https://blog.algomaster.io/p/15-types-of-databases
**Published:** March 24, 2024

## Summary

A survey of 15 database types covering their data models, use cases, examples, and when to choose each. Covers both classic (relational, hierarchical, object-oriented) and modern (vector, wide-column, ledger) categories.

## Types Covered

- [[Relational Model|Relational (RDBMS)]] — Tables with SQL, ACID, foreign keys
- [[Key-Value Store]] — Simple key-value pairs, high throughput
- [[Document Database]] — Semi-structured JSON/BSON documents
- [[Graph Database]] — Nodes, edges, and traversals
- [[Wide-Column Store]] — Dynamic columns, distributed at scale
- [[In-Memory Database]] — RAM-resident for microsecond latency
- [[Time-Series Database]] — Timestamped data points
- Object-Oriented Database — Objects with attributes and methods
- Blob Datastore — Large unstructured binary data
- Ledger Database — Immutable append-only records
- Hierarchical Database — Tree-structured parent-child records
- [[Vector Database]] — High-dimensional similarity search
- [[Embedded Database]] — Tightly integrated into applications
